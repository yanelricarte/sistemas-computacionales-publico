Tu sistema completo

Todo lo que hiciste desde la Clase 1 es un solo sistema, construido por capas. En esta clase, junto con tu grupo, vas a completarlo, practicar consultas, documentarlo y subirlo a GitHub. Es una clase de integración: se resuelve con todo lo de las Clases 1 a 5.

Materia: Proyecto, Diseño e Implementación de Sistemas Computacionales · 7.º año
Modalidad: trabajo en grupo, con esta guía como hoja de ruta
Entorno: tu proyecto + XAMPP (Apache + MySQL) · phpMyAdmin en http://localhost/phpmyadmin
Teoría de la clase: Integrar y documentar tu sistema (leela antes de empezar)

Objetivo

Dejar tu proyecto como un solo sistema con sus dos componentes funcionando: el sitio PHP (login, navegación, cartelera y ficha) y la base de datos MySQL (tu tabla con datos). Practicar consultas, documentar el sistema en un archivo que vas a completar en cada etapa, y dejar todo versionado. Al terminar, otra persona debería poder abrir tu repositorio y entender qué hace tu sistema.

Las películas son un ejemplo
Los ejemplos usan la cartelera de películas, pero trabajá con la entidad de tu proyecto (libros, juegos, productos, turnos…). Lo que se evalúa es que la estructura esté completa, no el tema.
Línea base: cuándo tu proyecto está completo
Tu sistema llega a la línea base (lo mínimo para darlo por completo) cuando:
  • el login funciona y una página interna redirige al login si no hay sesión;
  • la cartelera se arma sola con foreach (mínimo 4 elementos) y la ficha muestra uno por su id (y avisa si no existe);
  • la tabla MySQL existe con datos y corre un SELECT ... WHERE ...;
  • creaste el documentacion.md y todo está subido al repositorio.
Esa es la meta de hoy. Si ya la alcanzaste, seguí con las extensiones.

Parte 2 — Completá el sitio PHP

Completá lo que te quedó sin tildar, en este orden de prioridad:

  1. Login, sesión y protección: que puedas entrar y que una página interna te mande al login si no hay sesión.
  2. Includes y menú: cabecera.php y pie.php incluidos en todas las páginas.
  3. Cartelera con foreach (la lista se arma sola):
$items = require 'datos.php';
foreach ($items as $id => $it) {
    // una tarjeta por elemento + enlace a ficha.php?id=<?= $id ?>
}
  1. Ficha con lookup (buscar uno por su clave):
$id = $_GET['id'] ?? '';
$it = $items[$id] ?? null;
if ($it === null) { echo "No existe."; exit; }

Parte 3 — Completá la base MySQL

  1. Base y tabla (si no la tenés). Base con cotejamiento utf8mb4_unicode_ci; tabla con id como clave primaria autonumerada:
CREATE TABLE peliculas (
    id      INT AUTO_INCREMENT PRIMARY KEY,
    titulo  VARCHAR(100) NOT NULL,
    anio    INT,
    genero  VARCHAR(50)

  1. INSERT de mínimo 4 filas (no escribas el id; el texto va entre comillas simples).
  2. Consultas: SELECT *, un SELECT de columnas y al menos un filtro con WHERE.
  3. Exportá el script (pestaña Exportar → SQL) y dejá el .sql en la carpeta del proyecto.

Ahora resolvé estas consultas y anotá el resultado (cuántas filas trae cada una) en tu carpeta:

  1. Todas las películas ordenadas por año, de la más nueva a la más vieja. (pista: ORDER BY anio DESC)
  2. Solo titulo y anio de las estrenadas en 2015 o después.
  3. Todas las de género Animación.
  4. Las que duran más de 150 minutos, ordenadas de la más larga a la más corta.
  5. Las de Ciencia ficción anteriores a 2010 (pista: dos condiciones con AND).
  6. Las de Drama o Animación (pista: OR, o IN).
Preguntas para responder (con una consulta)
  1. ¿Cuál es la película más larga de la cartelera?
  2. ¿Cuántas películas de Animación hay? (pista: SELECT COUNT(*) ...)
  3. ¿Qué películas se estrenaron entre 1990 y 2000? (pista: BETWEEN)

Extensiones (si ya llegaste a la línea base)

Si tu grupo ya tiene todo el núcleo funcionando y subido, seguí con estas mejoras. Se resuelven con lo que ya sabés y suman al proyecto:

  1. Más datos y un campo nuevo. Llevá tu datos.php a 8 o más elementos y agregá un campo (por ejemplo imagen o duracion); mostralo en la cartelera y en la ficha. Sumá la misma columna a tu tabla MySQL.
  2. Más consultas sobre tu tabla. Escribí tres SELECT nuevos con ORDER BY, un filtro con AND/OR y un COUNT. Anotá para qué sirve cada uno en tu documentacion.md.
  3. Ficha más completa. Mostrá todos los campos del elemento y agregá un enlace "volver a la cartelera".
  4. Estilo por categoría. Con CSS (como en la Clase 3), dale un color o una clase distinta a las tarjetas según una categoría (género, tipo…).
  5. Adelantá la próxima etapa. Anotá en documentacion.md una segunda entidad con sus campos y tipos, y con qué entidad se relaciona. Si querés, dejá su estructura empezada en datos.php.
  6. Documentación al día. Completá la sección 6 (próximas etapas) con detalle y revisá que las secciones 1 a 5 describan tu proyecto real.

Errores comunes

ErrorQué revisar
La cartelera sale vacíaFalta return en datos.php, o el foreach recorre la variable equivocada.
La ficha no muestra nadaClave mal escrita ($it['titlo']) o el ?id= no coincide con una clave.
La página interna no protegeFalta session_start() o el chequeo con header('Location: ...').
SQL: "error in your SQL syntax"Falta ;, coma entre columnas o paréntesis.
El texto SQL da errorVa entre comillas simples; los números, sin comillas.
El WHERE no filtra bienRevisá el operador (>=, =) y que el texto vaya entre comillas simples.
