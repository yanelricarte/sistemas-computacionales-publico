Trabajo práctico · Clase 5

Tu primera base de datos en MySQL

Vas a pasar los datos de tu proyecto (los que en la Clase 4 estaban en datos.php) a una tabla real en MySQL: creás la base, la tabla con CREATE TABLE, cargás filas con INSERT y las consultás con SELECT. Al final exportás el script .sql y lo subís al repo.

Materia: Proyecto, Diseño e Implementación de Sistemas Computacionales · 7.º año
Entorno: XAMPP (Apache + MySQL) · phpMyAdmin en http://localhost/phpmyadmin

Objetivo

Elegir una entidad de tu proyecto (la cartelera de películas del ejemplo, o tu propio tema: usuarios, productos, turnos, libros…) y llevarla a una base de datos MySQL: CREATE TABLE con una clave primaria, INSERT de varias filas y SELECT para consultarlas. Es el primer contacto con la base de datos real que va a sostener tu proyecto.

Las películas son un ejemplo
Todo el TP usa la cartelera de películas para explicar, pero podés (y conviene) hacerlo con una entidad de tu proyecto. Lo que se evalúa es la estructura (tabla, tipos, PK, INSERT, SELECT), no el tema.
Antes de empezar
Abrí XAMPP y encendé Apache y MySQL. Entrá a http://localhost/phpmyadmin. Si algo no arranca, avisá: es un tema de entorno, no del TP. Repaso de conceptos en la teoría de Clase 5.

Consigna

Parte 1 — Diseñá tu tabla (en papel)

Antes de tocar phpMyAdmin, diseñá tu tabla en la carpeta. Elegí una entidad de tu proyecto y completá esta ficha de diseño: qué columnas tiene, de qué tipo es cada una (INT número, VARCHAR(n) texto, DATE fecha, BOOLEAN sí/no) y cuál es la clave primaria.

Tabla: ____________
┌──────────┬──────────────┬──────────────────┬───────┐
│ columna  │ tipo         │ ejemplo          │ ¿PK?  │
├──────────┼──────────────┼──────────────────┼───────┤
│ id       │ INT          │ 1, 2, 3          │  SÍ   │
│ ...      │ ...          │ ...              │       │
└──────────┴──────────────┴──────────────────┴───────┘
✓ Checkpoint Parte 1
tu ficha tiene mínimo 4 columnas + un id marcado como clave primaria (PK), y cada columna tiene decidido su tipo (número o texto). Recién con esto pasás a phpMyAdmin.

Parte 2 — Crear la base de datos

  1. En phpMyAdmin, creá una base nueva (botón Nueva).
  2. Nombre: el de tu proyecto (ej. cartelera). Cotejamiento: utf8mb4_unicode_ci (para que anden las tildes y la ñ).
  3. Entrá a la base y abrí la pestaña SQL: ahí vas a escribir los comandos.
✓ Checkpoint Parte 2
la base aparece en el panel izquierdo (todavía sin tablas). Estás parado adentro de ella (arriba dice su nombre).

Parte 3 — Crear la tabla (CREATE TABLE)

  1. Traducí tu entidad a una tabla: cada dato pasa a ser una columna con su tipo (INT números, VARCHAR(n) texto, DATE fechas, BOOLEAN sí/no). Agregá una columna id como clave primaria autonumerada: 
    CREATE TABLE peliculas (
    id      INT AUTO_INCREMENT PRIMARY KEY,
    titulo  VARCHAR(100) NOT NULL,
    anio    INT,
    genero  VARCHAR(50),
    imagen  VARCHAR(255)
);
  2. Cambiá peliculas y las columnas por las de tu entidad (mínimo 4 columnas + el id).
  3. Ejecutá (Continuar). La tabla aparece en el panel izquierdo.
✓ Checkpoint Parte 3
la tabla existe y tiene una columna id marcada como PRIMARY. Cada columna tiene su tipo. Si sale "syntax error", revisá las comas entre columnas y el ; final.

Parte 4 — Cargar filas (INSERT)

  1. Cargá mínimo 4 filas. No escribas el id: lo pone la base sola. 
    INSERT INTO peliculas (titulo, anio, genero, imagen) VALUES
    ('Matrix', 1999, 'Ciencia ficción', 'https://picsum.photos/seed/matrix/400/300'),
    ('Coco',   2017, 'Animación',       'https://picsum.photos/seed/coco/400/300'),
    ('Duna',   2021, 'Ciencia ficción', 'https://picsum.photos/seed/duna/400/300');
  2. Recordá: el texto entre comillas simples ('Matrix'), los números sin comillas (1999).
✓ Checkpoint Parte 4
clic en la tabla → pestaña Examinar: ves tus filas y la columna id numerada sola (1, 2, 3…).

Parte 5 — Consultar (SELECT)

  1. Traé toda la tabla: 
    SELECT * FROM peliculas;
  2. Traé solo algunas columnas: 
    SELECT titulo, anio FROM peliculas;
  3. Filtrá con una condición (WHERE). Al menos una consulta con filtro: 
    SELECT * FROM peliculas WHERE genero = 'Animación';
SELECT * FROM peliculas WHERE anio >= 2015;
✓ Checkpoint Parte 5
el SELECT * muestra todas las filas; el WHERE muestra menos (solo las que cumplen). Si el WHERE con texto no filtra, revisá las comillas simples del valor.

Parte 6 — Exportar el script y subirlo al repo

  1. En phpMyAdmin, con tu base seleccionada, andá a la pestaña Exportar → método rápido → formato SQL → Continuar. Se descarga un archivo .sql.
  2. Renombralo a db.sql (o cartelera.sql) y ponelo en la carpeta de tu proyecto.
  3. Subilo como un commit nuevo: 
    git add db.sql
git commit -m "Base de datos: tabla de mi entidad con CREATE, INSERT y SELECT"
git push
¿Por qué guardar el .sql?
Ese archivo es la receta de tu base: con él, cualquiera (o vos en otra máquina) recrea la tabla y los datos ejecutándolo. Es una de las entregas de esta etapa del proyecto (el script de creación de la base).

Parte 7 (opcional) — Si les sobra tiempo: más consultas

Para los grupos que ya terminaron. Escriban ustedes el SELECT de cada consigna sobre su misma tabla y anoten cuántas filas trae. No hay una única respuesta: depende de las columnas de tu entidad.

  1. Traé solo dos columnas que les interesen (ej. SELECT titulo, anio FROM ...).
  2. Traé las filas que cumplen una condición numérica (ej. WHERE anio >= 2015; o precio, edad, stock…).
  3. Traé las filas de una categoría exacta por texto (ej. WHERE genero = 'Animación'). Ojo con las comillas simples.
  4. Combiná dos condiciones con AND (traen las filas que cumplen las dos a la vez): 
    SELECT * FROM peliculas WHERE genero = 'Ciencia ficción' AND anio >= 2000;
  5. Si tu tabla tiene una fecha (DATE): traé las posteriores a una fecha (WHERE fecha_estreno >= '2015-01-01'). Si tiene un sí/no (BOOLEAN): traé solo las que están en verdadero (WHERE en_cartel = true).
