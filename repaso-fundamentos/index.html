1. Variables y sintaxis

Una variable es una caja con nombre donde guardás un valor. En PHP el nombre siempre empieza con $ y cada instrucción termina con ;.

$nombre = "Ana";       // texto (string): va entre comillas
$edad   = 17;          // número (int): SIN comillas
$activo = true;        // booleano: true o false

echo $nombre;          // muestra: Ana
echo "Hola " . $nombre; // el punto (.) concatena: "Hola Ana"
echo "Hola $nombre";    // dentro de comillas dobles, la variable se reemplaza sola
Comillas dobles vs simples
En "Hola $nombre" (dobles) la variable se reemplaza por su valor. En 'Hola $nombre' (simples) se muestra literal: Hola $nombre. Si dudás, usá dobles.

Asignar vs comparar: el error nº 1

SímboloQué haceEjemplo
=Asigna (guarda un valor)$x = 5;
==Compara si son igualesif ($x == 5)
===Compara valor y tipo'5' === 5 → falso
!=Compara si son distintosif ($x != 0)
Trampa clásica
if ($x = 5) NO compara: asigna 5 a $x y siempre da verdadero. Para comparar va if ($x == 5). Un solo = de más cambia todo.

Operadores útiles

// Matemáticos
$total = 10 + 5;   // suma 15
$resto = 10 % 3;   // módulo (resto de dividir): 1

// Comparación (devuelven true/false)
$a > $b    $a < $b    $a >= $b    $a <= $b

// Lógicos (combinan condiciones)
($edad >= 13 && $edad < 18)   // && = Y (las dos cosas)
($dia == 'sab' || $dia == 'dom')  // || = O (una u otra)

2. Estructuras selectivas (if / switch)

Las estructuras selectivas deciden qué código corre según una condición.

if / elseif / else — para rangos y condiciones

$nota = 7;

if ($nota >= 9) {
    echo "Excelente";
} elseif ($nota >= 6) {
    echo "Aprobado";
} else {
    echo "Desaprobado";
}
  • Se evalúan en orden: la primera condición verdadera gana y el resto se ignora.
  • elseif agrega más caminos; else es "en cualquier otro caso".
  • Ideal para rangos (≥, ≤) y condiciones combinadas con && / ||.

switch — para una variable contra valores fijos

$dia = 'lunes';

switch ($dia) {
    case 'sabado':
    case 'domingo':
        echo "Fin de semana";
        break;
    case 'lunes':
        echo "Arranca la semana";
        break;
    default:
        echo "Día de semana";
}
  • switch evalúa la variable una sola vez y salta al case que coincide.
  • break sale del switch. Sin break, sigue ejecutando el siguiente case (fall-through) — útil cuando dos casos comparten código (sábado y domingo arriba), peligroso si te lo olvidás.
  • default es el "else" del switch: corre si ningún case coincide.
¿Cuál uso?
¿Comparás una variable contra valores fijos (día, sección, opción de menú)? → switch.
¿Tenés rangos o condiciones combinadas (≥ 18, edad entre 13 y 17)? → if / elseif.

3. Estructuras repetitivas (for / while / foreach)

Las estructuras repetitivas (bucles) repiten un bloque de código varias veces.

for — cuando sé cuántas veces

for ($i = 1; $i <= 5; $i++) {
    echo $i;        // 12345
}

El for tiene tres partes, separadas por ;:

  • Arranque: $i = 1 (de dónde sale el contador).
  • Condición: $i <= 5 (mientras se cumpla, sigue).
  • Paso: $i++ (suma 1 en cada vuelta; $i++ es lo mismo que $i = $i + 1).

while — mientras se cumpla algo

$i = 1;
while ($i <= 5) {
    echo $i;        // 12345
    $i++;           // ¡importante! sin esto, no termina nunca
}
Bucle infinito
Si la condición del while nunca se vuelve falsa (te olvidaste de $i++), el programa se cuelga. Todo bucle tiene que avanzar hacia su final.

foreach — para recorrer un array

Es el bucle más cómodo para arrays: recorre cada elemento sin que tengas que llevar un contador.

$colores = ['rojo', 'verde', 'azul'];
foreach ($colores as $color) {
    echo $color;        // rojo verde azul
}

// En arrays asociativos, podés tomar clave Y valor:
$persona = ['nombre' => 'Ana', 'edad' => 17];
foreach ($persona as $clave => $valor) {
    echo "$clave: $valor";   // nombre: Ana   edad: 17
}
  • foreach ($array as $valor) → solo el valor de cada elemento.
  • foreach ($array as $clave => $valor) → la clave y el valor.
  • continue saltea la vuelta actual; break corta el bucle entero.
¿Cuál uso?
¿Recorrés un array? → foreach.
¿Repetís un número conocido de veces? → for.
¿Repetís mientras pase algo (sin saber cuántas)? → while.

4. Errores de sintaxis más comunes

ErrorQué revisar
Parse error: syntax error, unexpected ...Casi siempre falta un ;, una llave } o un paréntesis sin cerrar en la línea de arriba.
Undefined variable $xUsaste una variable que nunca creaste (¿typo en el nombre? ¿olvidaste el $?).
El if siempre da verdaderoPusiste = (asignar) en vez de == (comparar).
El texto sale con $nombre literalUsaste comillas simples; para interpolar la variable van comillas dobles.
El while no terminaFalta el paso que avanza el contador ($i++) o la condición nunca se vuelve falsa.
El switch ejecuta de másFalta un break al final del case (fall-through).
