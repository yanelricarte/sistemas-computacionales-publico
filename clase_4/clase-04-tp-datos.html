Trabajo práctico · Clase 4

Cartelera de películas con arrays y datos.php

A tu mini-sistema (el del login) le sumás una cartelera de películas. Cada película es un array asociativo, todas viven juntas en datos.php, la cartelera se arma sola con foreach y la ficha de cada película se busca con un lookup ??. Subís el avance como un nuevo commit.

Materia: Proyecto, Diseño e Implementación de Sistemas Computacionales · 7.º año

Objetivo

En Clase 3 elegías entre pocas secciones con un switch. Pero una cartelera tiene muchas películas parecidas: un switch con 20 casos sería absurdo. Para eso están los arrays. Vas a guardar cada película como un array asociativo (un registro), juntar todas en un archivo aparte (datos.php), armar la cartelera con un foreach y la ficha con un lookup ??. Es el puente hacia la base de datos que vamos a usar en la Clase 5.

Las películas son solo un ejemplo — usá el tema que quieras
Podés armar tu catálogo con lo que más te guste o con una entidad de tu proyecto: juegos, libros, canciones, recetas, jugadores, productos… Lo que importa es la estructura (array asociativo → datos.php → foreach → lookup), no que sean películas. Si elegís otro tema, cambiá las claves por las que tengan sentido (ej. un libro: titulo, autor, anio, imagen). Los ejemplos de abajo usan películas, pero adaptalos a lo tuyo.
Antes de empezar — repaso
Si algo de esto te cuesta, abrí el material de repaso de fundamentos (variables, if/switch, for/while/foreach). Recordá: = asigna, == compara; foreach recorre cada elemento de un array.

Consigna

Parte 1 — Una película como array asociativo

  1. Creá una variable con una película, juntando sus datos en un solo array con claves titulo, anio, genero, imagen: 
    $pelicula = [
    'titulo' => 'Matrix',
    'anio'   => 1999,
    'genero' => 'Ciencia ficción',
    'imagen' => 'https://picsum.photos/seed/matrix/400/300',
];
  2. Mostrala leyendo por la clave: <?= $pelicula['titulo'] ?>, <?= $pelicula['anio'] ?>, etc.
  3. Probá en el navegador que se vean bien los datos.
✓ Checkpoint Parte 1
¿podés leer el título con $pelicula['titulo']? Ojo con las comillas en las claves y con el =>.

Parte 2 — Todas las películas en datos.php

  1. Creá un archivo nuevo, datos.php, que devuelva (con return) un array de arrays con todas tus películas. La clave de la película es el id que va en la URL (?id=): 
    <?php
return [
    'matrix' => ['titulo' => 'Matrix', 'anio' => 1999, 'genero' => 'Ciencia ficción', 'imagen' => '...'],
    'coco'   => ['titulo' => 'Coco',   'anio' => 2017, 'genero' => 'Animación',       'imagen' => '...'],
    'duna'   => ['titulo' => 'Duna',   'anio' => 2021, 'genero' => 'Ciencia ficción', 'imagen' => '...'],
];
  2. Mínimo 4 películas.
✓ Checkpoint Parte 2
¿datos.php empieza con <?php y tiene return [ ... ];? Si te llega vacío, casi seguro te falta el return.

Parte 3 — La cartelera con foreach (cartelera.php)

  1. Creá cartelera.php: traé los datos y recorrelos con un foreach que arme una tarjeta por película: 
    <?php
  $peliculas = require 'datos.php';
?>

<?php foreach ($peliculas as $id => $peli): ?>
    <article class="pelicula">
        <img src="<?= $peli['imagen'] ?>" alt="<?= $peli['titulo'] ?>">
        <h3><?= $peli['titulo'] ?></h3>
        <p><?= $peli['anio'] ?></p>
        <a href="pelicula.php?id=<?= $id ?>">Ver ficha</a>
    </article>
<?php endforeach; ?>
  2. Probalo: agregá una película nueva a datos.php y recargá. Tiene que aparecer una tarjeta sola, sin tocar cartelera.php.
✓ Checkpoint Parte 3
agregás una película a datos.php → aparece sola en la cartelera. Ese es el sentido de separar los datos: tocás un solo archivo.

Parte 4 — La ficha con lookup (pelicula.php)

  1. Creá pelicula.php: buscá la película por el id de la URL con ?? y, si no existe, avisá en vez de romper: 
    <?php
  $peliculas = require 'datos.php';
  $id   = $_GET['id'] ?? 'matrix';
  $peli = $peliculas[$id] ?? null;

  if ($peli === null) {
      echo "Esa película no existe.";
      exit;
  }
?>

<h1><?= $peli['titulo'] ?></h1>
<p>Año: <?= $peli['anio'] ?> — <?= $peli['genero'] ?></p>
  2. Probá pelicula.php?id=coco y una inexistente (pelicula.php?id=avatar): tiene que avisar, no romperse.
✓ Checkpoint Parte 4
?id=avatar no rompe la página: el ?? null + el if la mandan al aviso. El switch no hizo falta en ningún lado.

Parte 5 — Nuevo commit (subí el avance)

Ya tenés el repo de Clase 3. Ahora subís el avance de hoy como un nuevo commit:

  1. Guardá todos los cambios (incluidos los archivos nuevos datos.php, cartelera.php y pelicula.php).
  2. En la terminal (Git Bash en VS Code: Ctrl + ñ): 
    git add .
git commit -m "Cartelera de peliculas: arrays asociativos, datos.php y foreach"
git push
  3. Entrá a tu repo en GitHub: tienen que aparecer los archivos nuevos y un commit más.
Opcional — techo
en la ficha (pelicula.php), agregá un link "Volver a la cartelera". Y en la cartelera, mostrá también el género de cada película.

Mantené lo de antes (no se borra)

  • session_start() y la protección de las páginas (login): la cartelera y la ficha también son páginas protegidas.
  • Los include 'includes/cabecera.php' / pie.php; agregá el link Cartelera al menú.

Errores comunes

ErrorQué revisar
datos.php llega vacío¿Le pusiste return antes del array? Sin return, require no trae nada.
La cartelera no muestra nada¿El foreach recorre $peliculas? ¿Hiciste el require 'datos.php' antes del foreach?
La ficha sale vacíaClave mal escrita: va <?= $peli['titulo'] ?> con el nombre exacto de la clave.
Una URL inexistente rompe la páginaFalta el ?? null y el chequeo if ($peli === null).
GitHub no acepta la contraseñaNo va la clave de tu cuenta: va el token o gh auth login con GitHub CLI.
