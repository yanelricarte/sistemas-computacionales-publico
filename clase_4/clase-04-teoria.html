0. Repaso: variables, sintaxis y estructuras selectivas

Antes de lo nuevo, afilamos las herramientas que más se traban. Si algo de esto te cuesta, tené a mano el repaso de fundamentos: es material para consultar todo el año.

Declarar variables y sintaxis

$nombre = "Ana";          // el $ adelante, comillas, ; al final
$edad   = 17;             // los números van SIN comillas
echo "Hola " . $nombre;   // el punto (.) concatena: pega textos
echo "Hola $nombre";      // dentro de comillas dobles, la variable se reemplaza

Tres símbolos que se confunden y rompen todo:

SímboloQué hace
=Asigna: guarda un valor en una variable. $x = 5;
==Compara si dos valores son iguales. if ($x == 5)
===Compara valor y tipo. '5' === 5 es falso (texto ≠ número).
Errores que vamos a cazar
Olvidar el $ de la variable, olvidar el ; al final, mezclar comillas, y escribir = (asignar) cuando querías == (comparar). El 90% de los "no me anda" salen de acá.

¿if/elseif o switch? (decidilo vos)

Las dos son estructuras selectivas: eligen qué código corre. La diferencia es cuándo conviene cada una.

  • if / elseif / else → para rangos y condiciones (mayor que, distinto, combinaciones con && / ||).
  • switch → para comparar una variable contra valores fijos (lo de Clase 3 con ?seccion=).

1. Arrays: común vs asociativo

Un array guarda varios valores en una sola variable. Hasta ahora usamos arrays comunes, donde cada valor tiene una posición numérica:

$colores = ['rojo', 'verde', 'azul'];
echo $colores[0];   // rojo  (la primera posición es 0)
echo $colores[2];   // azul

El array asociativo cambia los números por claves con nombre:

$pelicula = [
    'titulo' => 'Matrix',
    'anio'   => 1999,
    'genero' => 'Ciencia ficción',
    'imagen' => 'https://picsum.photos/seed/matrix/400/300',
];

echo $pelicula['titulo'];   // Matrix
echo $pelicula['anio'];     // 1999
  • La clave ('titulo') reemplaza al número de posición.
  • Se lee con $pelicula['clave'].
  • El símbolo => (operador de doble flecha) asocia cada clave con su valor.

Probá vos: dado el array de arriba, ¿cómo leés el valor de la clave genero? Escribilo y comprobá.

¿Por qué nombres y no números?
Con $pelicula['titulo'] sabés exactamente qué estás leyendo. Con $pelicula[0] tendrías que acordarte de que "la posición 0 era el título". Los nombres hacen el código legible.

2. Un array asociativo es un registro

Esta es la idea clave de la clase. Un array asociativo es lo mismo que una ficha o una fila de una tabla: campos con nombre y valor.

ARRAY ASOCIATIVO                  UNA FILA DE UNA TABLA
['titulo' => 'Matrix',             titulo | anio | genero
 'anio'   => 1999,                 -------+------+-----------------
 'genero' => 'Ciencia ficción',    Matrix | 1999 | Ciencia ficción
 'imagen' => '...']
  • Las claves (titulo, anio…) son los nombres de los campos: las futuras columnas.
  • El array entero es una fila (un registro): una película.
Guardá esta idea
Si un array asociativo es una fila, juntar varios va a ser… una tabla. Y ahí estamos a un paso de una base de datos de verdad (Clase 5).

3. Toda la cartelera junta (array de arrays)

En Clase 3, cada sección vivía adentro de un case del switch. Pero una cartelera tiene muchas películas parecidas: un switch con 20 casos sería absurdo. Las juntamos todas en un array de arrays. La clave de afuera es el id que viaja en la URL (pelicula.php?id=...).

$peliculas = [
    'matrix'       => ['titulo' => 'Matrix',       'anio' => 1999, 'genero' => 'Ciencia ficción', 'imagen' => '...'],
    'coco'         => ['titulo' => 'Coco',         'anio' => 2017, 'genero' => 'Animación',       'imagen' => '...'],
    'intensamente' => ['titulo' => 'Intensamente', 'anio' => 2015, 'genero' => 'Animación',       'imagen' => '...'],
];

echo $peliculas['coco']['titulo'];   // Coco  (entro por la clave de afuera y después por la de adentro)

Esto es la tabla: cada entrada de afuera es una fila (una película), y su clave ('coco') funciona como identificador.

entrá por las dos claves

echo $peliculas['coco']['titulo'];

Con el array de arrays de arriba, ¿qué imprime?

Y antes de seguir, conectemos esto con la base de datos que viene. Arrastrá cada elemento de tu código (o seleccionalo y tocá la zona) al lugar que ocuparía en una tabla. Al final tocá Verificar.

4. Datos en archivo aparte (datos.php)

Tener las películas mezcladas con la lógica ensucia el código. La solución: poner todas las películas en un archivo solo, datos.php, que devuelve el array con return.

<?php
// datos.php — SOLO datos
return [
    'matrix' => ['titulo' => 'Matrix', /* ... */],
    'coco'   => ['titulo' => 'Coco',   /* ... */],
];
// cartelera.php — trae los datos
$peliculas = require 'datos.php';

// ahora $peliculas tiene TODO lo que devolvió datos.php
  • require ejecuta datos.php y guarda lo que ese archivo returnea.
  • Ventaja enorme: para agregar o cambiar una película, tocás solo datos.php, no la lógica.

verdadero o falso

Si datos.php arma el array pero no le ponés return, $peliculas = require 'datos.php' igual recibe los datos.

require vs include
Los dos traen un archivo. La diferencia: require corta el programa si el archivo falta (mejor para datos imprescindibles); include sigue con un aviso. Para datos.php usamos require.

5. Buscar una película: lookup con ??

Con los datos en $peliculas, el switch ya no hace falta: buscamos la película por su clave (el id que vino en la URL).

$id   = $_GET['id'] ?? 'matrix';      // qué película pidió el usuario
$peli = $peliculas[$id] ?? null;      // esa película, o null si la clave no existe
  • $peliculas[$id] busca la película por su clave.
  • ?? null es el "plan B": si la clave no existe (ej. ?id=avatar), en vez de un error queda null y nosotros lo manejamos. Es el reemplazo del default del switch.
  • El switch desaparece: lo reemplaza una búsqueda en el array.
if ($peli === null) {                 // no existe: avisamos en vez de romper
    echo "Esa película no existe.";
    exit;
}

¿qué queda en $peli?

// el usuario entró a pelicula.php?id=avatar
// pero en datos.php NO existe la clave 'avatar'
$peli = $peliculas[$id] ?? null;

¿Qué queda en $peli?

Después, como la cabecera espera $titulo para el <title>, se lo pasamos desde la película antes del include:

$titulo = $peli['titulo'];
include 'includes/cabecera.php';

6. Recorrer con foreach (la cartelera que se arma sola)

Las estructuras repetitivas (bucles) repiten un bloque de código. Repaso rápido de las que ya viste:

for ($i = 1; $i <= 3; $i++) { echo $i; }     // 123  (arranque; condición; paso)
$i = 1; while ($i <= 3) { echo $i; $i++; }   // 123  (mientras se cumpla la condición)

comprobá: ¿cuántas veces corre?

for ($i = 0; $i < 4; $i++) { echo "x"; }

Probá antes de seguir.

Cuidado con el bucle infinito
En el while, si te olvidás de $i++, la condición nunca deja de cumplirse y el programa no termina. Todo bucle tiene que avanzar hacia su final.

Para recorrer un array, el bucle natural es foreach ("para cada elemento, hacé esto"). No necesita contador:

$colores = ['rojo', 'verde', 'azul'];
foreach ($colores as $c) { echo $c; }          // rojo verde azul

// con clave Y valor (para arrays asociativos):
foreach ($peliculas as $id => $peli) {
    echo $peli['titulo'];
}

La cartelera que se arma sola

Con foreach sobre $peliculas, la lista se genera sola: una tarjeta por película, sin escribirlas a mano.

<?php foreach ($peliculas as $id => $peli): ?>
    <article class="pelicula">
        <img src="<?= $peli['imagen'] ?>" alt="<?= $peli['titulo'] ?>">
        <h3><?= $peli['titulo'] ?></h3>
        <p><?= $peli['anio'] ?></p>
        <a href="pelicula.php?id=<?= $id ?>">Ver ficha</a>
    </article>
<?php endforeach; ?>
La recompensa
Agregás una película nueva a datos.php y recargás: aparece una tarjeta sola en la cartelera. No tocaste cartelera.php. Ese es el sentido de separar los datos de la presentación.

El $id de cada vuelta es la clave ('matrix', 'coco'…): por eso el link pelicula.php?id=<?= $id ?> lleva a la ficha correcta.

7. Errores frecuentes

SíntomaCausa y solución
datos.php llega vacíoFalta el return antes del array. Sin return, require no trae nada.
La cabecera sale sin títuloNo asignaste $titulo desde $peli antes del include.
La ficha sale vacíaUsaste una clave mal escrita: va <?= $peli['titulo'] ?> (con el nombre exacto de la clave).
La cartelera no muestra nadaEl foreach no recorre $peliculas, o $peliculas no se cargó con require antes del foreach.
Una URL inexistente rompe todoFalta el ?? null y el chequeo if ($peli === null) en el lookup.
Undefined array keyPediste una clave que no existe (ej. $peli['director'] cuando la película no tiene ese campo).

8. Glosario

TérminoQué es
Array asociativoArray cuyas posiciones son claves con nombre ('titulo' => 'Matrix') en vez de números.
Registro / filaUn conjunto de campos con nombre que describen una cosa. Un array asociativo es un registro.
Array de arraysUn array cuyos valores son, a su vez, arrays. Sirve para guardar varias filas.
=>Asocia una clave con su valor dentro de un array.
requireTrae y ejecuta otro archivo PHP; guarda lo que ese archivo returnea.
returnDevuelve un valor. En datos.php, devuelve el array a quien hizo el require.
??Operador "si no existe, usá esto". $a ?? $b vale $a si existe, si no $b.
foreachBucle que recorre cada elemento de un array, sin contador.
